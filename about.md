# Lazer UI

A smooth, music-reactive menu overhaul for Geometry Dash, inspired by osu!lazer.

- Pulsing, hover-reactive main menu logo
- Frame-rate independent animations with elastic / quint easing
- Anti-aliased rounded panels with soft shadows

*Not affiliated with or endorsed by ppy or osu!. Animation behaviour is adapted from the MIT-licensed osu! and osu-framework source code.*
